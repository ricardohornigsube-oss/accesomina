REGLA DE MARCA

El símbolo Pulso no se redibuja ni se modifica. Se utiliza siempre con sus bloques redondeados, ritmo escalonado y la paleta índigo–turquesa. La versión vertical es complementaria; la horizontal es la firma principal.
